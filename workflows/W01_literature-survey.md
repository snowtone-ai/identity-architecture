# W01 文献調査ワークフロー

目的: 特定の問い・概念・主張について、既存研究を効率的に把握する。
入口: `/lit <テーマ>` または手動。

## 手順
1. **問いの明確化**（メインコンテキスト）
   - 「何が分かれば次に進めるか」を1文で書く
2. **探索**（librarian サブエージェントに委譲）
   - OpenAlex MCP / Web検索で候補10〜30件を収集
   - 委譲時の指示: 「支持する文献と**反する文献の両方**を必ず探すこと」（憲章第7条）
   - 出力: 候補リスト（書誌+1行要約+関連度）のみをメインに返す
3. **選別**（研究者の判断）
   - 精読対象を3〜7件に絞る。Zotero に保存
4. **ノート化**
   - 重要文献のみ `literature/notes/` にノート作成
5. **証拠抽出**
   - 主張に関係する知見を `evidence/items/` へ。原典照合チェック必須
6. **クロージング**
   - reading-queue.md を更新。state/research-state.md に成果を1〜3行記録

## トークン節約規則
- PDF全文をメインコンテキストに読み込まない。サブエージェント内で読み、結論のみ返す
- 同一テーマの再調査時は、まず notes/INDEX.md を grep してから外部検索する
