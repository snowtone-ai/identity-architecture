# Identity Architecture Research OS

単独研究者が Claude App と Claude Code のみで「Identity Architecture（IA）」理論を長期的に構築・検証するための研究オペレーティングシステム。

---

## 設計思想

本リポジトリの中核は **主張台帳（Claim Ledger）** である。

- 理論は「文書」ではなく「検証可能な主張（Claim）の集合」として管理する
- すべての主張は、概念（Concept）と証拠（Evidence）に明示的にリンクされる
- 主張は反証探索を経なければ「支持」ステータスに昇格できない
- 確証バイアス対策は意志ではなく **構造** で実装する

### ここまでで分かったこと

11件の主張のうち、実証的に支持されたのは **CL-001（価値優先順位の時間的安定性）の1件のみ**。
残りの主張に共通するのは、**行動的DV（客観的行動記録）×縦断設計の文献空白**である。
「測定できないから支持しない」ではなく「そのような研究が分野全体で存在しない」という構造的欠落が確認された。

この事実を隠さず、信頼水準を明示したまま実務フレームワーク（IA-FRAMEWORK v0.1）を構築中。

```

├── CLAUDE.md              ← Claude Code が常時読み込む運用規則

```

## 命名規則

- **ディレクトリ名・ファイル名は ASCII**（git / grep / Claude Code ツールの安定性のため）
- **ファイルの中身はすべて日本語**（理論構築は日本語で行う）

| 種別 | ID形式 |
|---|---|
| 概念 | `C-001_<slug>.md` |

| 証拠 | `E-001_<slug>.md` |
| 反証 | `R-001_<slug>.md` |

## 研究の完全性ルール（最重要）

- 仮説と事実を混同して書かない。すべての理論的言明はステータスを付与する
- 主張を「支持」に昇格させる前に、必ず反証探索を実施し記録する
- `evidence/refutations/` のファイルは絶対に削除・改変しない（追記のみ）
- 証拠には必ず等級（E1〜E5）を付ける
- 出典のない経験的主張を概念・主張ファイルに書かない
