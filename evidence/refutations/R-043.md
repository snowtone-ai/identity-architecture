# R-043 CL-003b 反証条件閾値 r ≤ 0.15 の根拠が不在

- 登録日: 2026-06-12
- 対象: CL-003b
- 種別: 反証条件の設計欠陥
- 影響: 中程度

## 内容

CL-003b 反証条件は「自己記述変化と行動変化の相関が r ≤ 0.15 以下」で偽とするが、この閾値の出典・正当化がない。

自己報告と行動の相関は心理学全般で中程度（r ≈ 0.2–0.4、態度-行動ギャップ研究参照）に留まることが知られており、r = 0.15 を「深層変化の不在」の閾値とすると、正常な態度-行動相関の下限と区別がつかず、偽陰性（深層変化があるのに反証と判定）のリスクがある。

CL-003a の d < 0.2 は Cohen (1988) を根拠として引いているが、r ≤ 0.15 にはそうした参照がない。

## 影響

閾値が恣意的だと、反証条件が機能しない（高すぎる/低すぎる基準で誤判定）。

## 対応

r 閾値に文献根拠（態度-行動相関のメタ分析的基準値）を付すか、効果量基準を Cohen の慣例（小 r=0.1）に合わせて明記する。
