# R-023 CL-003 反証条件が現存研究で原理的に判定不能

- 登録日: 2026-06-12
- 対象: CL-003（アイデンティティ構造の再設計可能性）
- 種別: 反証可能性の構造的欠陥（反証条件の空振り）
- 影響: 致命的——反証条件①・②ともに価値優先順位DV×RCT研究が存在せず、主張の真偽を現存研究では原理的に判定できない

## 批判内容

**反証条件①**:「事前登録 RCT で Cohen's d < 0.2」
→ 価値優先順位・役割配置を DV とした RCT 自体が存在しない。条件が発火しない。

**反証条件②**:「6ヶ月後フォローアップで変化量が介入直後比 50% 未満に減衰」
→ 介入直後の変化量を価値優先順位 DV で測定した研究が支持側にゼロ。比較の分母がない。
CL-003 §5 自身が「健康成人対象かつ6ヶ月フォローアップを含む介入研究は現時点でゼロ」と認める。

この状況では:
- 支持研究からも「成立している」と言えず
- 反証条件が「充足された」と言えず
- 主張は安全に存続し続ける構造

反証条件が観察可能データに接続していない点において R-019（CL-007）と同型の問題。

## 対応要件

以下のいずれかが必要:
- (a) 反証条件を「現存の隣接研究（ACT/コーチング介入）から外挿可能な形」に書き換える
- (b) ステータスを「保留（検証手段なし）」または「検証不能（一次データ取得待ち）」に降格する
- (c) 自プロジェクト内の一次データ取得計画を明示し、検証タイムラインをコミットする
