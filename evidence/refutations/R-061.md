# R-061 反証閾値（r < 0.10）の根拠が未記載

- 対象主張: CL-010
- 批判種別: 中程度
- 登録日: 2026-06-12

## 内容
§3 主反証条件は「予測力が実質ゼロ（r < 0.10 または β < 0.10 相当）」を閾値とするが、この数値の根拠が記載されていない。

一般的な効果量の慣習（Cohen 1988）では r = 0.10 は「小効果」の下限であり、「実質ゼロ」とする根拠として広く使われる。しかし:
- 消費者行動研究では典型的効果量が r = 0.15〜0.30 の帯域に分布するため、r < 0.10 は相対的に厳しい基準となりうる
- E-035 の集約効果量 r = 0.31 に対し、反証閾値 r < 0.10 は非常に大きな効果量差を要求しており、意図-行動ギャップを考慮しても「行動 DV で r < 0.10」を要求する一方的さがある
- 閾値設定根拠の不在は、査読者・批判者が恣意的設定と指摘する根拠となる

## 対応推奨
Cohen (1988) または消費者行動分野の慣行を根拠として §3 に明記する。あるいは SESOI（Smallest Effect of Interest）の観点から「実購買行動への実用的予測力の下限」を理論的に設定し、その理由を記録する。
