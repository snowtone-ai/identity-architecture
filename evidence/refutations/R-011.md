# R-011 CL-006 反証記録: 反証条件 AUC ≤ 0.60 と E-025 の算術的衝突

- 対象主張: CL-006（自己定義ナラティブの言語的外在化の行動予測妥当性）
- 登録日: 2026-06-11
- 反証類型: 反証条件の構造的欠陥（算術的不整合・逃げ道の内包）

## 反証の内容

### 問題: AUC ≤ 0.60 閾値は「通常の自己報告測定精度」と算術的に重複する

CL-006 §3 の反証条件は「コーディングスコアを予測変数とし、客観的行動指標を結果変数とした回帰分析で **AUC ≤ 0.60**」を反証の閾値として設定している。

この閾値は CL-004/005 と同基準と説明されているが、以下の算術的衝突が存在する:

1. **E-025（Dang et al. 2020）の知見**: 自己報告測定値と行動測定値の相関は一般的に r ≈ 0.2〜0.3（「弱い」領域）。これは §5「反する証拠」として既に登録されている
2. **AUC 換算**: r ≈ 0.2〜0.3 は AUC ≈ 0.56〜0.58 に相当する
3. **衝突**: AUC 0.56〜0.58 は反証条件「AUC ≤ 0.60」の内側に入る

すなわち、CL-006 が対象とする「自己報告ナラティブ記述→客観的行動 DV」の予測精度は、行動科学の一般的測定精度から期待される範囲（AUC ≈ 0.56〜0.58）が既に反証ゾーンに入っている。

### 二重の構造的問題

この算術的衝突は二方向に問題をはらむ:

- **閾値が実質的に不可能に高い方向**: もし CL-006 が「AUC > 0.60 の証拠なしには支持不可」と意図するなら、自己報告行動測定の通常精度を超える基準を要求しており、現実に達成可能な証拠が存在しない
- **逃げ道が生まれる方向**: もし CL-006 が AUC ≈ 0.57 の証拠を「閾値に届かないが反証条件も発火しない」とグレーゾーンで扱うなら、不確定帯が構造的に存在し、主張が弱い証拠を永続的に抱えながら昇格できない状態に固着する

どちらの解釈でも反証条件が適切に機能しない。

## 影響評価
- **重大**: 命題B（行動予測妥当性）の反証条件が機能不全。閾値を E-025 の方法論的知見と整合する形に再設定する必要がある
- 修正案: AUC ≤ 0.60 を「r < 0.10 相当（偶然水準との実質的区別が不能）」または「AUC ≤ 0.55」など、主張の趣旨（「偶然水準を実質的に上回る」）と整合する閾値に置き換える
- CL-006b 分割後に命題B の反証条件を書き直す際に要解決
