# R-058 主反証条件が永遠に発火しない構造——文献空白下での反証不能

- 対象主張: CL-010
- 批判種別: 致命的
- 登録日: 2026-06-12

## 内容
§3 主反証条件は「self-congruity を購買の前に測定し、実購買行動を DV とした縦断研究で、予測力が実質ゼロであることを複数の独立研究が確認した場合」を反証とする。

しかし W01 で確認されたとおり、実購買行動を DV とした self-congruity 研究は 2024 年時点で分野全体に存在しない。「存在しない研究が複数一致して null を示す」という条件は定義上充足不能である。§3 自身も「現時点では反証条件は発火せず」と注記しているが、これは「現時点で反証不能」と等値である。

R-009 でも指摘されたこの問題が W04 第2回でも未解消のまま残っている。「将来研究が現れたら発火する」という期待は反証条件の現在的機能を失っている。

## 対応推奨
主反証条件を「分野に存在しない研究種別への依存」から脱却させる。具体的には:
(a) 現時点で存在するメタ分析（E-035）の行動的 DV サブセット効果量の再分析可能性を反証条件とする（E-067 の全文照合が前提）、または
(b) 意図 DV 研究群での effect size の上限を反証の間接指標として設定し、行動→意図の意図-行動ギャップ係数（r≈0.45〜0.55）で補正した上限推定値 r < 0.10 を条件とする。
