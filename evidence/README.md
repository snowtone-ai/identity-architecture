# evidence/ — 証拠層の運用ルール

## items/（証拠台帳）
- 1証拠 = 1ファイル（`E-XXX_<slug>.md`）
- 「証拠」とは、いずれかの主張の真偽に関係する観察・データ・文献中の知見である
- 文献そのものは literature/ で管理し、文献から抽出した**個別の知見**をここに登録する
- 必ず等級（E1〜E5、governance/quality-standards.md）を付与する

## refutations/（反証記録）
- 主張に反する証拠・反例・批判で重要なものを `R-XXX_<slug>.md` として独立保存する
- **このディレクトリのファイルは削除・改変禁止（追記のみ）**
- 棄却された主張の記録もここに残す。「都合の悪い記録が消えない」ことが単独研究の完全性を担保する（憲章第9条）

## なぜ証拠を文献から分離するのか
1つの文献は複数の主張に複数の向き（支持/反対）で関係する。文献単位の管理では「この主張の証拠状況」が一覧できない。証拠を原子化することで、主張ファイルの証拠表が機能する。
