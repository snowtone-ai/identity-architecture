# CL-012 アイデンティティ整合行動の系統的選好（Gravity 吸引命題）

- ステータス: 定式化済（未検証）
- 作成日: 2026-06-12 / 最終更新: 2026-06-13
- 適用領域: 個人のみ（組織・ブランド・地域への外挿は別主張として独立登録が必要・R-067）

## 1. 主張（真偽を問える1文）
個人は、自身の顕現中のアイデンティティ（価値優先順位・役割アイデンティティ・自己定義ナラティブのうち文脈的に活性化しているもの）と整合すると知覚される行動選択肢を、非整合の選択肢と比較して系統的に選好・実行する。

**重要な限定**:
- 「顕現中（salient）」に限定: アイデンティティを保有しているだけでは不十分。文脈による活性化が必要（IBM の dynamic construction; L-094）
- 「整合と知覚される」に限定: 客観的整合性ではなく主観的知覚が行動選好を媒介する。ただし整合知覚は行動選択の**前**に独立測定した設計のみ証拠採用（事後測定は循環論法・R-066）
- 「行動選択肢の選好」に限定: 実際の客観的行動記録が DV。態度・意図 DV での昇格禁止
- **連言疑義（R-068）**: 「選好（preference）」と「実行（actual behavior）」は intention-behavior gap が存在する別 DV。連言禁止ルール違反の可能性あり（分離をユーザー確認待ち）

## 3. 反証条件
この主張は、次の観察があれば偽となる:

1. **複数ドメイン横断メタ分析条件**: アイデンティティ顕現性の事前独立操作 × 客観的行動記録 DV × 縦断・実験設計 を満たす複数ドメイン横断メタ分析において、効果量 r < .10（帰無仮説と区別不能水準）

2. **ドメイン別反証条件**: CL-012 が包含する各ドメイン命題（CL-004b・CL-005b・CL-010）が全件、客観的行動 DV での効果量で r < .10 を示す

3. **文脈統制後消失条件**: 経済的誘因・習慣・社会規範を統制した後、アイデンティティ整合性の独自効果が消失する（ΔR² ≤ .01）

**現時点の評価**: 上記3条件を直接検証したメタ分析は分野全体で存在しない（文献調査 2026-06-12）。ステータスは「定式化済（未検証）」。

**反証条件上の構造的問題（R-064）**: 条件1は分野全体で充足データが存在しないため原理的に発火不能。条件2は「全件」の連言要求であり支持条件（単一ドメイン r>.10 で部分支持）と非対称。再設計が必要（条件1は既存ドメイン別データで判定可能な形式に書き換え、条件2の全件→主要ドメイン任意へ緩和 or 支持条件も全件に揃えることを検討）。

**整合知覚の事前測定要件（R-066）**: 行動測定の前にアイデンティティ整合知覚を独立測定した設計のみを証拠採用する。事後測定では「選んだ選択肢を整合と知覚していた」が同義反復になり主張が反証不能になる。

## 4. 対立説明（憲章第5条・必須）

| 代替説明 | この主張とどう識別できるか |
|---|---|
| 習慣・慣れ（アイデンティティ整合ではなく行動反復） | アイデンティティ顕現性を独立操作し、習慣強度を統制変数として投入した実験で効果が残存するか |
| 経済的誘因・コスト差（整合選択肢がたまたま安い・便利） | 選択肢のコスト・便益を均等化した実験条件で整合選好が残るか |
| 社会規範・同調圧力（整合選択が社会的に期待される） | 社会規範の強さを統制したうえで個人内アイデンティティの独自効果を確認できるか |
| 自己報告インフレ（実際の行動ではなく行動意図・自己評価が整合する） | 客観的行動記録 DV 限定の分析で効果量が維持されるか（Hertz & Krettenauer 2016 では縮小が確認） |
| 需要効果（プライミング操作が整合行動を期待していると被験者が気づく） | ブラインド条件・アイデンティティ操作を含まない自然変動デザインで効果が残存するか（R-069） |
| 逆因果・自己知覚理論（行動→アイデンティティ知覚の逆方向; Bem 1972） | アイデンティティ整合知覚を行動選択の前に独立測定した縦断設計で因果方向を確認できるか（R-069） |
| intention-behavior gap（整合選択肢を選好しても実行しない） | 選好測定と客観的行動記録 DV を分離して各々で効果量を確認できるか（R-068） |
