# CL-005 役割アイデンティティの言語的外在化の行動予測妥当性

- ステータス: 定式化済（未検証）
- 作成日: 2026-06-10 / 最終更新: 2026-06-10
- 適用領域: 個人（成人・非臨床）
- 分割元: CL-002（第2回批判セッションで主張設計欠陥を指摘→4命題に分解）

## 1. 主張（真偽を問える1文）
役割アイデンティティ（重要役割の顕現性・コミットメント・役割構成の自己評価）は言語的自己記述として外在化でき、その記述は当人の役割関連行動（就労関与・家族役割行動・市民活動等）を偶然水準を実質的に上回る水準で予測する。

## 2. 使用概念
- C-001 Identity Architecture の役割アイデンティティ要素（顕現性・コミットメント・役割構成の相対的優先順位）
- 外在化（言語的自己記述：役割重要度評定・役割コミットメントの言語化）
- 予測妥当性（外在化された記述が将来の役割関連行動と実質的な相関を持つこと）

## 3. 反証条件（必須）
この主張は、次の観察があれば偽となる:
- 役割アイデンティティの標準化自己記述（顕現性スケール・役割コミットメント評定等）を実施し、役割関連の**客観的行動指標**（就労時間・役割関与率・他者評定等）を結果変数とした回帰分析で **AUC ≤ 0.60**（または Cohen's f² < 0.02）
  - 閾値根拠: CL-004 と同基準（自己報告-行動相関の実態を踏まえた実質的最低水準）
- 上記を満たす事前登録済み縦断研究 2 件以上が反証結果を示す場合

## 4. 対立説明（憲章第5条・必須）
| 代替説明 | この主張とどう識別できるか |
|---|---|
| 役割-行動一致仮説（トートロジー）：役割コミットメント高い者が役割行動を多くするのは定義による同語反復 | 役割記述を測定し**異なる役割・異なる時点**での行動を予測することで識別できる |
| 状況制約仮説：役割行動は内的アイデンティティより外的状況（雇用環境・家族規範）に規定される | 状況変数（就業形態・家族構成）を統制しても役割アイデンティティ自己記述の予測力が残れば識別できる |

## 7. 批判セッション記録（W04）
- 実施日: 2026-06-11（第1回・critic サブエージェント）
- 判定: 致命的欠陥あり（R-005 を作成）
- 致命的欠陥1: 反証条件の非対称による識別不能性。反証は事前登録縦断2件＋客観的行動DVを要求する一方、支持側で同条件に立つのはE-026の1件（非事前登録）のみで、現状では原理的に偽にできない
- 致命的欠陥2: 客観的行動DVを持つ直接支持はE-026のみ。E-027は意図DV、E-028/029は横断・意図DVで核を直接支持しない（R-003同型の証拠水増し）
- 重大欠陥: E-026は習慣的献血者の選択バイアス＋逆因果＋単一研究。因果方向「外在化→行動」を支持する証拠は実質ゼロで、§4対立説明（トートロジー・状況制約）が未排除
- 軽微: 連言構造（外在化でき∧予測する）が残存（R-002/R-004 先例に抵触）
