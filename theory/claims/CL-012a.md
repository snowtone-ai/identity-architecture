# CL-012a アイデンティティ整合選択肢の系統的選好（Gravity 吸引・選好命題）

- ステータス: 定式化済（未検証）
- 作成日: 2026-06-13 / 最終更新: 2026-06-13
- 適用領域: 個人のみ（組織・ブランド・地域への外挿は別主張として独立登録が必要）
- 親主張: CL-012（発展的廃止）

## 1. 主張（真偽を問える1文）
個人は、顕現中のアイデンティティ（価値優先順位・役割アイデンティティ・自己定義ナラティブのうち文脈的に活性化しているもの）と整合すると知覚される行動選択肢を、非整合の選択肢と比較して系統的に高く選好する。

**重要な限定**:
- 「顕現中（salient）」に限定: 文脈による活性化が必要（IBM の dynamic construction; L-094）
- 「整合と知覚される」に限定: 主観的知覚が媒介する。整合知覚は行動選好の**前**に独立測定した設計のみ証拠採用（事後測定は循環論法リスク・R-066）
- **DV**: 行動選好・選択意向・好意度（自己報告可）。ただし客観的行動記録ではない（→実行については CL-012b）

**IBM との差別的予測（R-063 対応）**:
顕現する IA 要素の**種別**（価値 vs. 役割 vs. ナラティブ）によって、選好が強まる行動ドメインが異なる。
- 価値優先順位顕現時 → 価値表現行動（ドメイン横断の価値実現行動）が選好される
- 役割アイデンティティ顕現時 → 役割遂行行動（役割固有の義務・期待行動）が選好される
- 自己定義ナラティブ顕現時 → ナラティブ整合行動（過去の自己記述と連続する行動）が選好される

IBM（Oyserman 2009）は「identity salience」を要素種別を問わず一律に扱い、どの要素が顕現するかによって選好される行動ドメインが変わるという**要素種別×行動ドメイン特異性**の予測を持たない。この交互作用予測が CL-012a の IBM に対する独自貢献である。

**注**: 差別的予測は現時点で未検証（実験デザイン要件: 要素種別を独立操作し、行動ドメイン別の選好を DV とした 2×3 設計）。

## 3. 反証条件
この主張は、次の観察があれば偽となる:

**条件A（ドメイン別反証・既存データで判定可能）**:
主要ドメイン（道徳・環境配慮・職業役割）のいずれかにおいて、以下の設計を満たす研究で効果量 r < .10 が示された場合、当該ドメインでの反証条件が成立する:
- アイデンティティ顕現性の事前独立操作（または自然変動の事前測定）
- 整合知覚の行動選好測定**前**の独立測定
- 選好DV（意図・選択意向・好意度・相対選好）

**条件B（差別的予測の反証）**:
要素種別（価値 vs. 役割 vs. ナラティブ）を独立操作した実験において、行動ドメイン別の選好効果量が要素種別によって有意に変動しない（交互作用 η² < .01）場合、差別的予測が反証される（主主張の反証ではなく独自貢献の棄却）。

**条件C（文脈統制後消失）**:
経済的誘因・習慣・社会規範を統制した後、アイデンティティ整合性の独自効果が消失する（ΔR² ≤ .01）。

**現時点の評価**: 条件A を直接充足するドメイン別設計は複数存在するが、整合知覚の事前独立測定要件を満たすものが少ない（2026-06-13 時点）。条件B を充足するデータは分野全体で不在。

| 経済的誘因・コスト差（整合選択肢が安い・便利） | 選択肢のコスト・便益を均等化した実験条件で整合選好が残るか |
| 社会規範・同調圧力（整合選択が社会的に期待される） | 社会規範の強さを統制したうえで個人内アイデンティティの独自効果を確認できるか |
| 自己報告インフレ（選好自己報告が整合バイアスを含む） | 選好の暗黙的測定（反応時間・潜在的態度）と明示的自己報告が収束するか |
| 需要効果（プライミング操作が整合選好を期待していると被験者が気づく） | ブラインド条件・アイデンティティ操作を含まない自然変動デザインで効果が残存するか（R-069） |
| 逆因果・自己知覚理論（選好→アイデンティティ知覚の逆方向; Bem 1972） | アイデンティティ整合知覚を選好測定の前に独立測定した縦断設計で因果方向を確認できるか（R-069） |
| IBM で十分な説明が可能（要素種別の差別化不要） | 要素種別×行動ドメイン交互作用の有意性を確認できるか（R-063 への回答） |
