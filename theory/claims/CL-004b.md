# CL-004b 価値優先順位のドメイン固有自己記述の行動予測妥当性

- ステータス: 定式化済（未検証）
- 作成日: 2026-06-11 / 最終更新: 2026-06-11
- 適用領域: 個人（成人・非臨床）
- 分割元: CL-004（連言主張を分解。B命題のみを独立登録。A命題「外在化可能性」は測定具の存在で自明のため独立ファイルを省略し本ファイル前提として記録）

## 1. 主張（真偽を問える1文）
価値優先順位の**ドメイン固有**自己記述（職業価値観・組織価値観・消費価値観・政治価値観等、特定行動ドメインに照準した価値記述）は、当人の当該ドメインにおける将来の行動・意思決定（職業選択・組織コミットメント・投票行動・購買行動等）を偶然水準を実質的に上回る水準で予測する。

※一般的道徳価値観（Schwartz SVS 全10類型等）の行動予測妥当性は本主張のスコープ外（E-024 参照。E-024 はスコープ限定の根拠であり反証ではない）。
※前提（省略したA命題）: 価値優先順位は SVS・PVQ 等の標準化自己記述として言語的に外在化できる——これは測定具の存在から自明であり、独立した検証対象としない。

## 2. 使用概念
- C-001 Identity Architecture の価値要素（価値優先順位：重みづけられた価値群の相対的序列）
- ドメイン固有価値記述（特定行動文脈に照準した価値の言語化：職業価値観票・組織適合度評定・消費価値スケール・政治価値評定等）
- 予測妥当性（外在化された記述が当該ドメインの将来行動・意思決定指標と実質的な相関を持つこと）

## 3. 反証条件（必須）
この主張は、次の観察があれば偽となる:
- ドメイン固有価値記述（職業・政治・消費いずれか）を実施し、**同ドメインの客観的行動指標**（職業選択・投票記録・購買行動等、自己報告以外で測定）を結果変数とした回帰分析で **AUC ≤ 0.60**（または Cohen's f² < 0.02）
  - 閾値根拠: CL-005 と同基準（自己報告-行動相関の実態 r≈0.2〜0.3 を踏まえた実質的最低水準）
- 上記を満たす事前登録済み縦断研究 2 件以上が反証結果を示す場合
- 非対称回避：支持側の昇格にも客観的行動DV縦断を2件以上要求する（R-005 の教訓）

## 4. 対立説明（憲章第5条・必須）
| 代替説明 | この主張とどう識別できるか |
|---|---|
| 共通方法分散仮説：価値測定も行動意図測定も自己報告ゆえ相関が水増しされる | 客観的行動指標（投票記録・購買履歴・採用記録等）を用いると相関が消えるなら共通方法分散が原因 |
| 状況決定論：行動は内的価値より外部状況（雇用市場・制度）に規定される | 状況変数を統制しても価値記述の予測力が残れば識別できる |
| 社会的望ましさバイアス：価値記述は実際の動機でなく演技を反映 | 社会的望ましさ尺度を共変量として統制しても予測力が残れば排除できる |
| 同語反復：ドメイン価値と同ドメイン行動の相関は定義的に高い | 異なる時点で価値と行動を測定し、かつ価値記述がそのドメインの「他者」行動を予測しないことを確認して識別する |
