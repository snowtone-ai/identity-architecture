# CL-012b アイデンティティ整合選択肢の系統的実行（Gravity 吸引・実行命題）

- ステータス: 定式化済（未検証）
- 作成日: 2026-06-13 / 最終更新: 2026-06-13
- 適用領域: 個人のみ（組織・ブランド・地域への外挿は別主張として独立登録が必要）
- 親主張: CL-012（発展的廃止）

## 1. 主張（真偽を問える1文）
個人は、顕現中のアイデンティティ（価値優先順位・役割アイデンティティ・自己定義ナラティブのうち文脈的に活性化しているもの）と整合すると知覚される行動選択肢を、非整合の選択肢と比較して客観的に記録可能な行動として系統的に高い頻度・確率で実行する。

**重要な限定**:
- 「顕現中（salient）」に限定: 文脈による活性化が必要（IBM の dynamic construction; L-094）
- 「整合と知覚される」に限定: 整合知覚は行動実行の**前**に独立測定した設計のみ証拠採用（事後測定は循環論法リスク・R-066）
- **DV**: 客観的行動記録のみ（観察記録・行動ログ・生理指標・実験室行動課題）。態度・意図・自己報告行動頻度での昇格禁止
- CL-012a（選好命題）との関係: 選好と実行の間には intention-behavior gap が存在し、CL-012a の支持は CL-012b の支持を意味しない

**IBM との差別的予測（R-063 対応）**:
CL-012a と同様、顕現する IA 要素の**種別**（価値 vs. 役割 vs. ナラティブ）によって、客観的行動として実行される行動ドメインが異なる。
- 価値優先順位顕現時 → 価値表現行動（ドメイン横断の価値実現行動）が実行される
- 役割アイデンティティ顕現時 → 役割遂行行動（役割固有の義務・期待行動）が実行される
- 自己定義ナラティブ顕現時 → ナラティブ整合行動（過去の自己記述と連続する行動）が実行される

IBM は「identity salience」を要素種別を問わず一律に扱い、この要素種別×行動ドメイン特異性の予測を持たない。

**注**: 差別的予測・主主張ともに現時点で客観的行動 DV での証拠はゼロ件（R-065 継承）。

## 3. 反証条件
この主張は、次の観察があれば偽となる:

**条件A（ドメイン別反証・将来データで判定可能）**:
主要ドメイン（道徳・環境配慮・職業役割）のいずれかにおいて、以下の設計を満たす研究で効果量 r < .10 が示された場合、当該ドメインでの反証条件が成立する:
- アイデンティティ顕現性の事前独立操作（または自然変動の事前測定）
- 整合知覚の行動実行測定**前**の独立測定
- **客観的行動記録 DV**（観察・ログ・実験室課題等）

**条件B（差別的予測の反証）**:
要素種別（価値 vs. 役割 vs. ナラティブ）を独立操作した実験において、客観的行動記録 DV での要素種別×行動ドメイン交互作用が有意でない（η² < .01）場合、差別的予測が反証される。

**条件C（intention-behavior gap が本命題の系統的消失を示す）**:
CL-012a（選好）が支持された条件下で、客観的行動記録 DV でのみ効果量が r < .10 に縮小することが複数ドメインで確認された場合、選好から実行への変換が系統的に失敗することを示し、本命題は棄却される。

**現時点の評価**: 条件A を充足するデータ（客観的行動DV × 事前整合知覚測定 × 実験設計）は分野全体で不在。条件B・C も同様に不在。本命題は「証拠空白」の状態にある。

## 4. 対立説明（憲章第5条・必須）

| 代替説明 | この主張とどう識別できるか |
|---|---|
| Intention-behavior gap（整合選択肢を選好しても実行しない） | CL-012a と CL-012b の効果量差を直接比較できるか（CL-012a支持 ∧ CL-012b棄却 が成立するか） |
| 習慣・慣れ（実行は整合選択ではなく過去行動の反復） | 習慣強度を統制した後、アイデンティティ顕現性の独自効果が客観的行動DV で残存するか |
| 経済的誘因・コスト差（整合選択肢が安い・便利） | コスト均等化条件での客観的行動DV で整合実行が残るか |
| 社会規範・同調圧力（整合行動が社会的に観察・期待される） | 観察される設定 vs. 観察されない設定で効果量差があるか |
| 需要効果（プライミング操作が整合行動を期待させる） | ブラインド条件・自然変動デザインで客観的行動DV の効果が残存するか（R-069） |
| 逆因果・自己知覚理論（行動→アイデンティティ知覚の逆方向; Bem 1972） | アイデンティティ整合知覚を行動実行の前に独立測定した縦断設計で因果方向を確認できるか（R-069） |
| IBM で十分な説明が可能（要素種別の差別化不要） | 要素種別×行動ドメイン交互作用の有意性を客観的行動DV で確認できるか（R-063 への回答） |

## 5. 証拠
