# CL-006 自己定義ナラティブの言語的外在化の行動予測妥当性

- ステータス: 定式化済（未検証）
- 作成日: 2026-06-10 / 最終更新: 2026-06-10
- 適用領域: 個人（成人・非臨床サンプルを優先するが臨床証拠も参照）
- 分割元: CL-002（第2回批判セッションで主張設計欠陥を指摘→4命題に分解）

## 1. 主張（真偽を問える1文）
自己定義ナラティブ（可能自己・人生テーマ・贖罪語り等の自己物語）は言語的自己記述として外在化でき、その記述内容（テーマ・主題的構造）は当人の将来の行動・意思決定を偶然水準を実質的に上回る水準で予測する。

## 2. 使用概念
- C-001 Identity Architecture のナラティブ要素（自己定義ナラティブ：人生テーマ・重要出来事の意味構造）
- 外在化（言語的自己記述：自己物語・可能自己・人生テーマの言語化と内容分析コーディング）
- 予測妥当性（外在化された記述内容が将来の観察可能な行動・意思決定指標と実質的な相関を持つこと）

## 3. 反証条件（必須）
この主張は、次の観察があれば偽となる:
- 標準化ナラティブ課題（人生物語インタビュー・可能自己記述等）のコーディングスコアを予測変数とし、**客観的行動指標**（学業成果・職業行動・健康行動等）を結果変数とした回帰分析で **AUC ≤ 0.60**
  - 閾値根拠: CL-004/005 と同基準
- 健康成人サンプルで上記の反証結果が確認された場合（臨床サンプルのみの反証は条件付き反証として扱う）

## 4. 対立説明（憲章第5条・必須）
| 代替説明 | この主張とどう識別できるか |
|---|---|
| 事後的意味付け仮説（Dennett 1991 / McAdams 1993）：ナラティブは行動の事後的再解釈であり将来行動を規定しない | 測定時点と行動測定時点を6ヶ月以上離した遅延予測デザインで事後性を排除できる |
| コーダー主観性仮説：ナラティブコーディングのスコアは評価者間信頼性が低く測定誤差が大きい | 評価者間信頼性（κ or ICC）が適切な水準（κ ≥ 0.70）を満たした研究のみで再現するかを確認できる |
| 臨床-健常差異仮説：E-021（断酒）はアルコール依存の文脈特有で健常成人には適用できない | 健康成人サンプルでの独立した縦断研究で再現するかを確認することで識別できる |
