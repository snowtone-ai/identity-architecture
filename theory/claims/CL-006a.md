# CL-006a 自己定義ナラティブの言語的外在化可能性（測定論的命題）

- ステータス: 定式化済（未検証）
- 作成日: 2026-06-11 / 最終更新: 2026-06-11
- 適用領域: 個人（成人・非臨床）
- 分割元: CL-006（R-010: 連言禁止ルール違反により分割。命題A「外在化可能性」を独立登録）

## 1. 主張（真偽を問える1文）
自己定義ナラティブ（可能自己・人生テーマ・贖罪語り等の自己物語）についての自己報告記述と訓練された評定者によるコーディングは、実質的な収束妥当性（r ≥ 0.30 または ICC ≥ 0.60 相当）を示す。

※ W04 批判セッション（R-013）により、元の表現「外在化できる（産出可能性）」と反証条件「収束する（測定法収束）」が概念的に非等価であることが確認された。主張文を測定論的命題として正直に定式化するため、上記の通り改訂（2026-06-11）。「産出可能性」（語り手が自己物語を言語として産出できること）は別命題として扱う。

## 2. 使用概念
- C-001 Identity Architecture のナラティブ要素（自己定義ナラティブ：人生テーマ・重要出来事の意味構造）
- 外在化（言語的自己記述：自己物語・可能自己・人生テーマの言語化と内容分析コーディング）
- 収束妥当性（自己報告記述と評定者コーディングが測定する構成概念の一致度）

## 3. 反証条件（必須）
この主張は、次の観察があれば偽となる:
- 標準化ナラティブ課題（人生物語インタビュー・可能自己記述等）において、自己報告ナラティブ尺度と訓練された評定者コーディングの収束相関が r < 0.30（または ICC < 0.60）であり、その結果が複数の独立研究チームで確認された場合
- または、評定者コーディング（主題コーディング）の評価者間信頼性が κ < 0.60 であることが複数の独立チームで確認された場合（測定の再現可能性の欠如）

※閾値根拠: r = 0.30 は「中程度の相関」の下限（Cohen 1988）。同一構成概念を測定する2測定法として最低限の収束を示す水準。

## 4. 対立説明（憲章第5条・必須）
| 代替説明 | この主張とどう識別できるか |
|---|---|
| 測定非等価仮説（E-056 の主張）：自己報告ナラティブと評定者コーディングは異なる構成概念を測定しており収束しない | 収束相関が体系的に低い（r < 0.30）研究の複数独立確認で識別 |
| コーダー訓練依存仮説：高訓練コーダーのみで収束が得られ、標準的研究条件では再現しない | 訓練水準を統制した比較研究で識別 |
| 語り様式依存仮説：構造化インタビューではなく非構造化自由記述では収束が崩れる | 課題形式を統制した研究で識別 |

## 7. 批判セッション記録（W04）
- 実施日: 2026-06-11（CL-006 W04 の一部として記録）
- **追加実施日: 2026-06-11（critic サブエージェント・独立批判）**
- 主要な批判点（1回目）:
  1. 命題A（外在化可能性）には元の CL-006 で反証条件が設定されていなかった（R-010）
  2. E-056 による直接的な測定論的反証候補が存在するが全文未照合
  3. E-052〜055 は外在化可能性の直接検証ではなく、コーディング使用の実施事例に過ぎない

- 主要な批判点（2回目・W01 後・R-013・R-014 登録）:
  1. **概念的非等価（R-013）**: 「外在化できる（産出可能性）」≠「自己報告とコーディングが収束する（測定法収束）」。反証条件が主張本体を捕捉していない致命的設計欠陥 → §1 主張文を測定論的命題に改訂
  2. **証拠基準の非対称（R-014）**: 支持候補 E-057/058 は開発者自己検証（1件で可）、反証には複数独立チーム要求。証拠構図は「開発者＝肯定・独立追試＝否定」でバイアス方向に一貫 → E-057/058 を開発者自己検証として格下げ
  3. **全証拠未照合（致命的）**: 支持・反証を分ける r 値・ICC 値が全件未取得。検証の前提数値が存在しない
  4. **r≥0.30 閾値根拠の脆弱性**: Cohen の効果量慣習を異種法収束に転用するのは根拠不足（重大）
  5. **CL-006b 前提依存の過剰結合**: 行動予測にはコーディング信頼性（κ≥0.70）だけで足り、自己報告との収束は不要 → CL-006b 側を修正
- **結論: 昇格不可。主張文改訂・証拠基準対称化・E-056/057/058 全文照合 + 独立追試の確認が必要条件**
