# CL-003a アイデンティティ構造の意図的再設計可能性（方向性付き変化命題）

- ステータス: 定式化済（未検証）
- 作成日: 2026-06-12 / 最終更新: 2026-06-12
- 適用領域: 個人（成人・非臨床サンプル）
- 分割元: CL-003（連言主張の分解・R-024 指摘への対応。命題(a)のみを独立登録）

## 1. 主張（真偽を問える1文）
意図的介入（コーチング・ナラティブ療法・ACT等）により、Identity Architecture の**価値・役割優先順位配置を意図した方向に**変化させることができる（無方向の変動ではなく、目標とした配置への接近として測定できる）。

※連言分解の根拠: 元の CL-003 は「再設計可能(a)・深層構造変化(b)・6ヶ月持続(c)」の連言。本ファイルは(a)のみ。(b)は CL-003b、(c)は CL-003c として独立登録。
※R-025 対応: 「再設計」定義に「意図した方向への変化（目標配置への接近）」を明示。無方向変動では支持とならない。

## 2. 使用概念
- C-001 Identity Architecture の価値優先順位・役割優先順位要素
- 意図的介入: 構造化された介入手続き（コーチング・ナラティブ療法・ACT等）
- **方向性付き変化**: 介入前に設定した目標配置と介入後の実測配置の一致度として操作化（単なる変化量ではなく方向ベクトルの正値）

## 3. 反証条件（必須・対称設計）
この主張は、次の観察があれば偽となる:
- 意図した目標配置への変化を DV とした RCT で、介入群と対照群の差が Cohen's d < 0.2（小効果量以下）
- 変化の方向が目標配置と一致しない（ランダム変動と統計的に区別できない）
- 上記を満たす事前登録済み縦断研究 2 件以上

**現状の問題（R-023 対応）**: 価値・役割優先順位配置変化を DV とした RCT が現存しないため、現時点では検証手段なし。ACT の「valued living」は本 DV と構成概念が一致しない（R-021）。

## 4. 対立説明（憲章第5条・必須）
| 代替説明 | この主張とどう識別できるか |
|---|---|
| 一過性同調仮説: 介入中は目標配置への接近を示すが、介入終了後に元の配置に戻る | 介入直後と終了後追跡で変化の方向性維持を確認（CL-003c と合わせた検証が必要） |
| 測定反応性: 目標配置への接近が実際の変化でなく尺度への反応バイアスを反映している | 間接測定（行動観察・他者評定）との収束妥当性で識別 |
| 自然成熟仮説: 変化は介入でなく加齢・成熟の自然プロセス | RCT 無介入対照群との比較で識別 |
| 出版バイアス: 有効な介入研究のみが公開されている | 事前登録研究・否定的結果の登録・ファンネルプロット非対称性検定 |
| **平均への回帰（R-039）**: ベースラインが極端な参加者が再測定で自然に中央値へ戻り、介入効果と混同される | 無作為割付と極端スコア層別分析で識別 |
| **要求特性（R-039）**: 参加者が介入の目的を推測し回答を合わせる（社会的望ましさとは別機序） | IAT 等の間接測定・行動観察との乖離で識別 |
| **非特異的効果・共通要因（R-039）**: 特定の介入技法の効果でなく、注目・期待・関係性による効果 | 能動的対照群（等量の非特異的注意）との比較で識別 |
| **選択バイアス（R-039）**: 完遂者のみで効果が見え、変化動機の低い脱落者が除外されている | 意図分析（ITT）で脱落者込みの効果推計 |
| **目標配置の設定主体問題（R-040）**: 目標を介入者が設定すれば要求特性と区別不能、本人設定なら表面同調と同義になる | 目標設定主体を明記し、独立した客観的変化指標（行動観察・他者評定）で確認 |
