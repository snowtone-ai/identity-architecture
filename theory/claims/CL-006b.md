# CL-006b 外在化された自己定義ナラティブのコーディングスコアの行動予測妥当性

- ステータス: 定式化済（未検証）
- 作成日: 2026-06-11 / 最終更新: 2026-06-11
- 適用領域: 個人（健康成人・非臨床）
- 分割元: CL-006（R-010: 連言禁止ルール違反により分割。命題B「行動予測妥当性」を独立登録）
- 前提: CL-006a（外在化可能性）が支持されることが本命題の前提。CL-006a が棄却された場合、本命題は検証不能として「保留」へ遷移する

## 1. 主張（真偽を問える1文）
外在化された自己定義ナラティブのコーディングスコア（テーマ・主題的構造）は、**健康成人サンプル**の将来の行動・意思決定を偶然水準を実質的に上回る水準で予測する（効果量 r > 0.10 相当）。

※「行動・意思決定」とは自己報告以外の客観的指標（職業選択記録・健康行動記録・学業成果等）を指す。ウェルビーイング・精神的健康 DV のみでの昇格は禁止（CL-006 の教訓。健康成人×客観的行動DV の直接支持が必要条件）。

## 2. 使用概念
- C-001 Identity Architecture のナラティブ要素（自己定義ナラティブ：人生テーマ・重要出来事の意味構造）
- ナラティブコーディングスコア（訓練された評定者が標準プロトコルで付与するテーマ・主体性・贖罪語り等の構造的スコア）
- 予測妥当性（コーディングスコアが将来の観察可能な行動・意思決定指標と実質的な相関を持つこと）

## 3. 反証条件（必須）
この主張は、次の観察があれば偽となる:
- **健康成人**サンプルを対象に、標準化ナラティブ課題のコーディングスコアを予測変数とし、**客観的行動指標**（職業行動・健康行動・学業成果等。自己報告を DV としない）を結果変数とした縦断研究で、効果量 r < 0.10（または d < 0.20）相当の実質ゼロ結果が複数研究で確認された場合
  - 閾値根拠: r = 0.10 は「小効果量の下限」（Cohen 1988）。「偶然水準を実質的に上回る」と主張するために必要な最低水準
  - ※ AUC ≤ 0.60 は E-025 の算術的衝突（R-011）により廃止。r < 0.10 を代替閾値として設定
- 臨床サンプルのみの反証は「条件付き反証」として扱い、健康成人への適用可否を独立評価する

## 4. 対立説明（憲章第5条・必須）
| 代替説明 | この主張とどう識別できるか |
|---|---|
| 事後的意味付け仮説（Dennett 1991 / McAdams 1993）：ナラティブは行動の事後的再解釈であり将来行動を規定しない | 測定時点と行動測定時点を6ヶ月以上離した遅延予測デザインで事後性を排除できる |
| コーダー主観性仮説：コーディングスコアは評価者間信頼性が低く測定誤差が大きい | 評価者間信頼性（κ or ICC ≥ 0.70）を満たした研究のみで再現するかを確認できる |
| 臨床-健常差異仮説：E-021（断酒）はアルコール依存の文脈特有で健常成人には適用できない | 健康成人サンプルでの独立した縦断研究で再現するかを確認することで識別できる |
| ウェルビーイング代理仮説：ナラティブが予測するのは精神的健康であり、行動変数を DV にすれば効果は消える | 客観的行動 DV を使用した研究での効果が残るかで識別 |

## 6. 反証探索の記録（昇格の必須条件）
- 実施日: 2026-06-11（CL-006 W01 調査・W04 批判セッションで確認）
- 探索状況: 健康成人×客観的行動DV を同時充足する縦断研究が分野全体で不在と確認（Adler et al. 2016 が分野の公式課題として明示）
- 次ステップ: W01 文献調査の追加実施（"narrative prediction behavioral outcomes healthy adults" / "possible selves objective behavior" 等）。前提 CL-006a の W01 と同時実施を推奨

## 7. 批判セッション記録（W04）
- 実施日: 2026-06-11（CL-006 W04 の一部として記録）
- 主要な批判点:
  1. 元の反証条件 AUC ≤ 0.60 は E-025 と算術的に衝突（R-011）。r < 0.10 に置き換え
  2. 中核母集団（健康成人×客観的行動DV）の直接支持がゼロ（R-012）
  3. E-020（青年期）・E-021（臨床）は母集団断絶により昇格根拠として無効
  4. E-052〜055 は DV が精神的健康のため命題B の支持証拠として不適格
- 結論: 昇格不可。有効証拠ゼロ。W01 による直接証拠の探索が必要条件
