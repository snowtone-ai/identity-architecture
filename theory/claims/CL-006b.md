# CL-006b 外在化された自己定義ナラティブのコーディングスコアの行動予測妥当性

- ステータス: 定式化済（未検証）
- 作成日: 2026-06-11 / 最終更新: 2026-06-11
- 適用領域: 個人（健康成人・非臨床）
- 分割元: CL-006（R-010: 連言禁止ルール違反により分割。命題B「行動予測妥当性」を独立登録）
- 前提（R-028 対応・2026-06-12 改訂）:
  - 前提1: ナラティブコーディングの評価者間信頼性 κ ≥ 0.70（測定の再現性）
  - 前提2: コーディングスコアが自己定義ナラティブという構成概念を正しく捉えていること（構成概念妥当性）
  - ~~「CL-006a が棄却されても本命題の検証は可能」~~ → **撤回（R-028）**。CL-006a（収束妥当性）の棄却はコーディングスコアの構成概念妥当性に影響しうる。E-056（Gehrt 2024）が示す収束妥当性の欠如は、コーディングスコアが「別の構成概念」を測定している可能性を含意し、CL-006b の前提を直接脅かす。

## 1. 主張（真偽を問える1文）
外在化された自己定義ナラティブのコーディングスコア（テーマ・主題的構造）は、**健康成人サンプル**の将来の行動・意思決定を偶然水準を実質的に上回る水準で予測する（効果量 r > 0.10 相当）。

※「行動・意思決定」とは自己報告以外の客観的指標（職業選択記録・健康行動記録・学業成果等）を指す。ウェルビーイング・精神的健康 DV のみでの昇格は禁止（CL-006 の教訓。健康成人×客観的行動DV の直接支持が必要条件）。

## 2. 使用概念
- C-001 Identity Architecture のナラティブ要素（自己定義ナラティブ：人生テーマ・重要出来事の意味構造）
- ナラティブコーディングスコア（訓練された評定者が標準プロトコルで付与するテーマ・主体性・贖罪語り等の構造的スコア）
- 予測妥当性（コーディングスコアが将来の観察可能な行動・意思決定指標と実質的な相関を持つこと）

## 3. 反証条件（必須）
この主張は、次の観察があれば偽となる:
- **健康成人**サンプルを対象に、標準化ナラティブ課題のコーディングスコアを予測変数とし、**客観的行動指標**（職業行動・健康行動・学業成果等。自己報告を DV としない）を結果変数とした縦断研究で、効果量 r < 0.25（または d < 0.50）相当の結果が**同一設計の独立研究2件以上**で確認された場合
  - 閾値根拠: E-025（Dang et al. 2020）は自己報告と行動測定の一般的相関を r≈0.20〜0.30 とする。測定誤差・共通方法分散のみで発生しうる r=0.10 を閾値とすると反証不能に近い（R-029）。r ≥ 0.25 を「理論的予測が一般測定誤差を超えた水準」として採用
  - 支持と反証の対称化: 支持にも「独立2件以上・事前登録済み」を最低条件とする
  - ※ AUC ≤ 0.60 は E-025 の算術的衝突（R-011）により廃止済み
- 臨床サンプルのみの反証は「条件付き反証」として扱い、健康成人への適用可否を独立評価する
- 【R-028 対応・追加】: コーディングスコアの構成概念妥当性が複数の独立指標（行動観察・間接測定等）で確認できない場合、本命題の検証自体が無効（何を測定したかが不明）

## 4. 対立説明（憲章第5条・必須）
| 代替説明 | この主張とどう識別できるか |

| 【R-028 追加】構成概念妥当性問題：コーディングスコアは自己定義ナラティブとは別の構成概念（言語流暢性・記憶の再現性・開示傾向等）を測定しており、予測力がナラティブ構造に起因しない | 収束妥当性確認（コーディングスコアと自己報告ナラティブスコアの相関）および弁別妥当性確認（言語流暢性・記憶力との相関統制後も増分予測が残るか）で識別 |
| 臨床-健常差異仮説：E-021（断酒）はアルコール依存の文脈特有で健常成人には適用できない | 健康成人サンプルでの独立した縦断研究で再現するかを確認することで識別できる |
| ウェルビーイング代理仮説：ナラティブが予測するのは精神的健康であり、行動変数を DV にすれば効果は消える | 客観的行動 DV を使用した研究での効果が残るかで識別 |

## 7. 批判セッション記録（W04）

### 第1回（2026-06-11・CL-006 W04 の一部として実施）
- 主要な批判点:
  1. 元の反証条件 AUC ≤ 0.60 は E-025 と算術的に衝突（R-011）。r < 0.10 に置き換え
  2. 中核母集団（健康成人×客観的行動DV）の直接支持がゼロ（R-012）
  3. E-020（青年期）・E-021（臨床）は母集団断絶により昇格根拠として無効
  4. E-052〜055 は DV が精神的健康のため命題B の支持証拠として不適格
- 結論: 昇格不可。有効証拠ゼロ。W01 による直接証拠の探索が必要条件

### 第2回（2026-06-12・CL-006b 専用・critic サブエージェント）
- 致命的欠陥2件（R-028・R-029）、重大問題3件、軽微問題2件
- **R-028（致命）**: 前提独立性の主張が E-056 と矛盾。CL-006a 棄却時、コーディングスコアの構成概念妥当性が未確立になり、何を測ったかが不明になる。κ ≥ 0.70 は再現性しか保証せず構成概念妥当性は別問題。
- **R-029（致命）**: 支持下限 r > 0.10 は E-025（r≈0.20〜0.30 が一般相関）より低い。測定誤差のみで達成可能な閾値であり事実上反証不能。→ r ≥ 0.25 に引き上げ・支持/反証の証拠数対称化（§3 更新済み）
- 重大問題①: 反証は「複数研究」要件・支持は単発可能という非対称構造（§3 で対称化済み）
- 重大問題②: 臨床証拠を反証にも支持にも使えなくする「条件付き反証」条項が母集団基準の恣意的適用
- 重大問題③: E-025 は自己報告-行動の相関であり IV=コーディングスコアの参照値として不整合（§3 から除外）
- 軽微問題①: 文献空白を「定式化済（未検証）」の根拠とする楽観的解釈（研究者の非魅力評価の可能性）
- 軽微問題②: 「健康成人」「客観的指標」の境界が操作的に未定義
- **判定: 昇格不可。ステータス「検証手段未確立（保留）」への降格を検討すべき。** 最低修正条件: (1)前提改訂（R-028）、(2)閾値引き上げ・証拠数対称化（R-029）→ 両方 §3 更新済み。ステータスは「定式化済（未検証）」維持（未証拠は文献空白によるものであり、設計自体は修正可能）
