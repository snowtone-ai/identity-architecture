# CL-004 価値優先順位の言語的外在化の行動予測妥当性

- ステータス: 棄却（発展的廃止・CL-004b に分割）
- 作成日: 2026-06-10 / 最終更新: 2026-06-11
- 適用領域: 個人（成人・非臨床）
- 分割元: CL-002（第2回批判セッションで主張設計欠陥を指摘→4命題に分解）

## 1. 主張（真偽を問える1文）
価値優先順位（Schwartz 等の理論に基づく価値ランキング）は言語的自己記述として外在化でき、その記述は当人の将来の行動・意思決定（職業選択・投票・日常行動等）を偶然水準を実質的に上回る水準で予測する。

## 2. 使用概念
- C-001 Identity Architecture の価値要素（価値優先順位：重みづけられた価値群の相対的序列）
- 外在化（言語的自己記述：価値ランキング・重要度評定の言語化）
- 予測妥当性（外在化された記述が将来の観察可能な行動・意思決定指標と実質的な相関を持つこと）

## 3. 反証条件（必須）
この主張は、次の観察があれば偽となる:
- 価値優先順位の標準化自己記述課題（SVS・PVQ 等）を実施し、**客観的行動指標**（職業選択・投票・役割関与行動等、自己報告以外で測定）を結果変数とした回帰分析で **AUC ≤ 0.60**（または Cohen's f² < 0.02 ＝ small effect 未満）
  - 閾値根拠: 自己報告-行動相関の実態（r≈0.2〜0.3; Dang et al. 2020 E-025）を踏まえ、偶然水準（AUC=0.5）ではなく実質的予測力の最低水準（AUC=0.60, r≈0.32 相当）を基準とする
- 上記を満たす事前登録済み縦断研究 2 件以上が反証結果を示す場合

## 4. 対立説明（憲章第5条・必須）
| 代替説明 | この主張とどう識別できるか |
|---|---|
| 共通方法分散仮説：価値測定も行動測定も自己報告ゆえ相関が水増しされる | 客観的行動指標（投票記録・行動観察等）を用いると相関が消えるなら共通方法分散が原因 |
| 適応的演技仮説：自己記述は社会的望ましさバイアスで実際の行動動機を反映しない | 社会的望ましさ尺度を共変量として統制しても予測力が残れば演技仮説を排除できる |
| 一般的価値の限界仮説（E-024）：一般的道徳価値観は行動を予測しないが、ドメイン固有の価値記述は予測できる | ドメイン固有価値（職業価値観・政治価値観等）と一般価値を同一研究内で比較することで識別できる |

## 7. 批判セッション記録（W04）

### 第1回批判セッション（2026-06-10）

**致命的欠陥**:
1. **連言主張の未分解**（R-004 参照）：「外在化できる(A) ∧ 行動を予測する(B)」の連言形式。(A) は測定具が存在する時点でほぼ自明。論争命題は (B) のみ。連言にしたことで自明な (A) が論争的な (B) を担保するかのような誤印象を生む。プロジェクト規則（連言主張の登録禁止）違反
2. **証拠と反証条件の不整合**：反証条件は「客観的行動指標」を要求しているが、支持証拠3件中2件（E-019・E-023）はDVが自己報告。客観的行動DVの支持は E-022（媒介あり）のみ。客観的行動DVで実施された反証 E-024 は予測力消失。土俵を揃えると「支持0〜1・反証1」

**重大な問題**:
1. E-019（被引用1件・再現未確認）・E-023（自己報告DV）を E3 格付けは過大評価。CMV補正後の実効支持は E-022 の0.5件相当
2. 反証条件「AUC≤0.60」が事実上反証困難な設計（典型値r≈0.2〜0.3の上端に閾値、かつ事前登録2件要件）。支持側に同等要件なし—非対称な反証ハードル
3. 主張がSchwartz一般価値を含むと宣言しながら、反証E-024（一般価値→予測力消失）を「ドメイン固有なら予測できる」で回避—スコープの事後縮小

**軽微な問題**:
- E-025 の §2 関係主張 ID が CL-002 のまま（CL-004 未参照）→修正済み
- 「実質的に上回る」とAUC≤0.60の対応関係が本文に明示されていない
- E-022 の媒介と予測妥当性の概念整理が不足

**判定：昇格不可**（「定式化済（未検証）」の維持は妥当）。連言分解・スコープ確定・証拠基準対称化を先に実施すること
