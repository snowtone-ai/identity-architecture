# 品質基準（Quality Standards）v1.0

## 1. 証拠等級（Evidence Grading）

すべての証拠ファイルに以下の等級を必ず付与する。

| 等級 | 定義 | 例 |
|---|---|---|
| E1 | 体系的・査読済みの強い証拠 | メタ分析、複数の再現された実験、システマティックレビュー |
| E2 | 査読済みの個別研究 | 単一の査読論文（実験・調査・定量分析） |
| E3 | 体系的だが未査読 | プレプリント、政府統計、質の高い業界データ |
| E4 | 事例・定性的記述 | ケーススタディ、ジャーナリズム、一次資料の記述 |
| E5 | 逸話・個人的観察 | 自身の観察、伝聞、単発の逸話 |

運用規則：
- E4・E5 は「着想の源」としては有効だが、単独で主張を「支持」に昇格させることはできない
- 主張の昇格には E2 以上の証拠が最低1件、または E3 が独立に2件必要
- 再現性危機の影響が大きい分野（社会心理学等）の E2 は、再現状況を必ず確認・記載する

## 2. 主張ステータス遷移規則

```
着想 → 定式化済 → 検証中 → ┬→ 支持（暫定）
                            ├→ 棄却
                            └→ 保留（検証手段なし）
```

| 遷移 | 必要条件 |
|---|---|
| 着想→定式化済 | 主張テンプレートの全項目（特に反証条件）が記入済み |
| 定式化済→検証中 | 検証計画（どの文献・データで検証するか）が記載済み |
| 検証中→支持（暫定） | (a)等級条件を満たす支持証拠 (b)反証探索の実施記録 (c)批判セッション通過 (d)対立説明の検討記録 の4点すべて |
| 検証中→棄却 | 反証となる証拠の登録。棄却理由を記録（ファイルは削除しない） |

「支持」は常に「暫定」である。確定ステータスは存在しない。

## 3. 概念の品質チェックリスト

新概念は以下を満たすまで「未成熟」ステータスとする。
- [ ] 1文の定義がある
- [ ] 既存学術概念との異同が文献付きで記述されている（憲章第8条）
- [ ] 適用例と非適用例（境界例）が各2つ以上ある
- [ ] 操作化の方向性（観察・測定の手がかり）が記述されている、または「操作化困難」と明記されている

## 4. 文献ノートの品質基準
- 書誌情報（著者・年・誌名・DOI）必須
- 「この文献が本プロジェクトのどの概念・主張に関係するか」のリンク必須
- 主張を引用する際はページ番号または節番号を記録
- AIが生成した要約は必ず原典と照合してから台帳に登録する（引用ハルシネーション対策）
